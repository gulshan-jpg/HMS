Security, Privacy & Infrastructure

CheckinOS is engineered from the ground up to protect your property's guest identities, reservation ledgers, and financial records with enterprise-grade defensive architecture.

1. Data Encryption & Transmission

In Transit: TLS 1.3 Strict

All HTTP connections are strictly forced over TLS 1.3 with HSTS (HTTP Strict Transport Security) enabled. Legacy protocols and insecure ciphers are blocked at the perimeter.

At Rest: AES-256 GCM

All databases, automated snapshot archives, and file uploads are encrypted at rest using industry-standard AES-256 keys with hardware security module (HSM) key rotation.

2. Multi-Tenant Isolation Architecture

CheckinOS enforces strict logical tenant segregation across all layers:

  • Session-Level Context Validation: Every request validates the organization binding from cryptographically signed JWT tokens.
  • Row-Level Security (RLS) Event Hooks: ORM query pipelines automatically inject tenant-scoping clauses into every database query, ensuring zero possibility of cross-property data leakage.
  • Optimistic Concurrency Protection: Versioned records prevent concurrent edits from overwriting front desk updates.

4. Backup Policy & Disaster Recovery

  • Automated Snapshots: Encrypted database snapshots are taken automatically every 24 hours (hourly on Pro and Enterprise tiers).
  • 30-Day Point-in-Time Retention: Backups are retained offsite across multiple availability zones for 30 rolling days.
  • One-Click Self-Serve Export: Hoteliers can download complete, raw CSV exports of their entire property database at any time.
