Product Changelog

New features, performance upgrades, and security improvements shipped to CheckinOS.

v1.0.0 November 24, 2026
Commercial B2B SaaS Launch

The official production release enabling multi-tenancy, self-serve onboarding, billing, and enterprise hospitality data safety.

  • New Multi-Tenant Architecture: Complete row-level isolation per hotel organization with custom subdomains and branding logo uploads.
  • New Self-Serve Onboarding & 14-Day Trial: Instant signup with auto-seeded realistic boutique hotel demo data and a 7-step onboarding wizard.
  • New Stripe Subscription Engine: Tiered plans (Starter, Pro, Enterprise) with Stripe Checkout, customer billing portal, and plan limit enforcement.
  • New Mobile Housekeeping Views: Cleaning staff can access floor-grouped rooms via secure 24-hour links without logins.
  • New CSV Bulk Import Wizard: Pre-validated bulk import for guest lists and room inventories with downloadable templates.
  • New ReportLab PDF Invoices: Sequential fiscal tax invoicing with CGST/SGST/IGST breakdowns and print-ready A4 formatting.
  • Security Audit Log Engine & Optimistic Locking: Before/after state diff tracking for all entity changes, plus version-based concurrent booking collision detection.
  • Improved One-Click Data Safety: Automated encrypted backups, trash bin with soft-delete restores, and single-click full ZIP CSV data export.
v0.9.0 November 10, 2026
Tier-1 Core Hospitality Engine

Foundational PMS features designed to match commercial hospitality standards.

  • New Availability Timeline (Gantt): Visual room rack with conflict detection and drag-and-drop reservations.
  • New Split Folios & Group Bookings: Multi-folio billing, room charges, corporate allocations, and master room routing.
  • New Dynamic Rate Plans: Flexible, non-refundable, and length-of-stay discount rules with automated cancellation policy calculations.
  • New Automated Night Audit: Business date rollover, daily snapshot balance checks, and manager closing logs.
